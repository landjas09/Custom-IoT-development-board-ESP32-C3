# Custom-IoT-development-board-ESP32-C3
A custom-designed IoT dev board built around the ESP32-C3, featuring integrated LiPo battery charging, environmental sensing, ambient light sensing, audio capture, on-board storage (flash,SD card), and a USB-C interface with full USB-to-UART programming support. Designed end-to-end in KiCad 10, from schematic capture through PCB layout and routing.
